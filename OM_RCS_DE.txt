|                      | 	0xE0E0 Offline,                                                     |

|                      |    0xF111 DRY (Kein Treibstoff) und in B den Tankfüllstand.            |
|                      |                                                                        |
|                      | Version 0x0008 fügt zusätzlich ERROR 0xFFFF hinzu, wenn zu             |
|                      | viel Bewegung vorliegt, um genutzt zu werden.                          |
| Triebwerkszündung    | A = 0x0001                                                             |
|                      | C = Dauer in ms                                                        |
|                      | XYZ = Richtung:                                                        |
|   Version 0x0002     | Richtung ist nur 0 oder 1.                                             |
|   Version 0x0004     | Richtung ist ein Wert zwischen 0x0000 und 0x00FF.                      |
|   Version 0x0009     | Richtung ist ein Wert zwischen 0x0000 und 0xFFFF.                      |
|                      | Zusätzlicher Autostop-Interrupt: C = 0xFFFF                            |
|                      | verbraucht mehr Treibstoff, kann aber Bewegungen unter 1 Einheit/min   |
|                      | und Gesamtrotation unter 5 Grad/min unterdrücken. Diese Version hat    |
|                      | zusätzlichen Status ERROR für zu hohe Bewegungen, um genutzt zu werden.|
