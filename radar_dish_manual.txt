;
; EXAMPLE
;

:DEV_RADAR DAT 0xFFFF
; find_devices

SET B, 0xFB4F   ; max speed and distance
SET A, 0x0010   ; call set radar speed\range
HWI [DEV_RADAR] ; interupt - void

SET A, 0x0080   ; call get current count
HWI [DEV_RADAR] ; interupt - now in B
SET I, 0x0000   ; for (int i = 0 ; ...
:loop
    IFE I, B            ; for (int i = 0; i < b; ... with if equal
        SET PC, end

    SET A, 0x00F2       ; call get data of I
    HWI [DEV_RADAR]     ; Z is size AB is the ID of the object
    
	;SET A, 0x00D1		; call get position by B,C
	; or 
    SET A, 0x00F1		; call get position by I
	
	;X,Y,Z is now the location 
	; maybe to be displayed on sped-3
	
    
    ADD I, 1            ; for (int i = 0; i < b; i++)1
    SET PC, loop
:end


Notes: angles in the XYZ will be rounded on output 
User is responsible for tracking objects.
The "Size of object" is a collision sphere that engulves the object
